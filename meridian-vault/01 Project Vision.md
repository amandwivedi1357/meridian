# Project Vision

Meridian should be a resume-grade trading system, not a toy dashboard.

The main engineering story:

- trustworthy market data
- decimal-safe financial math
- exchange-documented local order book synchronization
- event-driven ingestion through Redis Streams
- historical storage in TimescaleDB
- a shared strategy interface for backtesting and live execution
- risk controls and kill switch
- observability through Prometheus and Grafana
- a frontend dashboard that makes the system understandable
