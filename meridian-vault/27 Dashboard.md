# Dashboard

The dashboard will make Meridian visible and demo-friendly.

## Planned Screens

- market view
- candlestick chart
- order book depth
- trades tape
- positions
- orders and fills
- strategy controls
- global kill switch
- system health
- backtest results

## Design Direction

This should feel like an operational trading system, not a marketing page.
